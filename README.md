### What I Learned

During this project, I practiced building responsive layouts using modern CSS techniques. I improved my understanding of Flexbox for alignment and spacing, and I used CSS variables to create a more maintainable stylesheet.

One concept I particularly enjoyed using was `clamp()` for responsive typography:

```css
:root {
  --font-sm: clamp(12px, 1vw, 16px);
  --font-md: clamp(12px, 2vw, 16px);
  --font-lg: clamp(24px, 2.5vw, 26px);
}
```

I also reinforced my knowledge of creating reusable components and interactive hover/focus states.
